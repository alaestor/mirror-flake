# Evaluate actual use

Reads count retrieval only. After applying a memory, optionally report
`memory feedback <id> useful`, `relevant-unused`, or `off-base`.
Add `--comment '...'` for a concrete correction, mismatch, or useful observation.
Do not manufacture feedback for every read. Off-base feedback opens a review;
it does not mechanically prove the article incorrect. Check whether the trigger
caused an irrelevant retrieval before rewriting accurate content.
