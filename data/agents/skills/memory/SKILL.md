# Memory

Use `memory explain authoring` before admitting knowledge. Use `memory maintain`
for the current findings and curation procedure. For targeted work, read
`memory explain feedback`, `memory explain verification`, or
`memory explain promotion`. These CLI-rendered prompts are the authority for
this procedure; do not invent a parallel memory workflow.

For substantial curation, follow the fresh-context, read-only subagent procedure
in `memory explain curation` when delegation is available and permitted. The
parent owns review and applies accepted changes. If delegation is unavailable,
leave the work pending unless the user has asked for curation directly.
